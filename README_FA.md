# خانوم دردسر — نسخه اولیه

ربات گروه تلگرام فارسی با پاسخ متنی/ویس، بازی‌های ساده، عضویت اجباری در کانال و تبلیغات زمان‌بندی‌شده.

## نکات مهم پیش از اجرا
- این پروژه یک نسخه آغازین است و هنوز روی سرور نصب یا به تلگرام متصل نشده است.
- ربات را در کانال `@Mb_silk` ادمین کن تا `getChatMember` بتواند عضویت کاربران را بررسی کند.
- برای خواندن پیام‌های گروه، در BotFather دستور `/setprivacy` را برای ربات اجرا و Privacy Mode را خاموش کن؛ سپس ربات را از گروه خارج و دوباره اضافه کن. در صورت نیاز ربات را ادمین کن.
- به ربات فقط مجوزهای لازم را بده.
- برای ارسال تبلیغات، هر گروه باید با اطلاع مدیرش ربات را اضافه کند. مدیر گروه می‌تواند با `/ads_off` تبلیغات را خاموش کند.
- شروع تماس تصویری گروهی خودکار توسط Bot API پشتیبانی نمی‌شود؛ ربات فقط می‌تواند زمان‌بندی و یادآوری کند و ادمین تماس را شروع کند.

## نصب روی سرور لینوکس
1. Python 3.11 یا جدیدتر نصب کن.
2. فایل‌ها را روی سرور قرار بده.
3. محیط مجازی بساز:
   `python3 -m venv .venv`
4. فعال کن:
   `source .venv/bin/activate`
5. وابستگی‌ها:
   `pip install -r requirements.txt`
6. فایل تنظیمات:
   `cp .env.example .env`
7. در `.env` مقدار `BOT_TOKEN` را وارد کن. برای پاسخ هوشمند، `AI_API_KEY` را نیز تنظیم کن.
8. اجرا:
   `python bot.py`

## تست اولیه
- در خصوصی ربات `/start` و `/voice_test` بفرست.
- ربات را به یک گروه آزمایشی اضافه کن.
- مدیر گروه `/ads_on` را بزند.
- برای پاسخ‌گویی، پیام را با «خانوم دردسر» خطاب کن یا به پیام ربات ریپلای بده.

## محدودیت‌های نسخه آغازین
- تشخیص «بحث جالب» در این نسخه محافظه‌کارانه است: فقط وقتی ربات خطاب شود پاسخ می‌دهد تا گروه را اسپم نکند.
- صدای فارسی با Edge TTS تولید می‌شود و برای تولید صدا به اینترنت نیاز دارد؛ دسترس‌پذیری سرویس و شرایط استفاده آن ممکن است تغییر کند.
- تبلیغات با فاصله پیش‌فرض ۱۲ ساعت ارسال می‌شوند؛ تنظیمات بیشتر و پنل وب در نسخه بعدی قابل افزودن است.
- دیتابیس SQLite برای نمونه اولیه است؛ برای مقیاس بالا بهتر است PostgreSQL و صف پردازش اضافه شود.
